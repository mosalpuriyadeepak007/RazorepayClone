# RazorepayClone

This is a front-end clone of the Razorpay marketing site built for learning and practice. It reproduces the visual layout using HTML, Tailwind CSS, and assets included in the repository.

## Features
- Responsive marketing pages
- Tailwind CSS utility classes
- Local assets (images, icons)

## Getting started
1. Clone the repository:

   git clone https://github.com/mosalpuriyadeepak007/RazorepayClone.git

2. Install dependencies (if you plan to build Tailwind assets):

   npm install

3. Run a local static server to preview (or open `index.html` directly):

   npx serve .

   or

   npx http-server .

4. To rebuild Tailwind CSS (if project uses a build step):

   npm run build

## Notes
- `node_modules/` should not be committed; it has been removed and is listed in `.gitignore`.
- This is not an official Razorpay project — it's an educational clone.
